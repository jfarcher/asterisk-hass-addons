# Home Assistant Add-on: Asterisk

A phone system for your home, run by [Asterisk](https://www.asterisk.org/), that you set up in plain language from the Home Assistant sidebar.

- **Phones**: add desk phones, phone apps, Home Assistant SIP cards and SIP doorbells, with step-by-step connection details and live status.
- **Automatic setup** for Yealink, Grandstream, Snom, Fanvil and Poly desk phones.
- **Outside lines**: connect a SIP provider to make and receive ordinary phone calls.
- **Apps**: one-click setup for [Kiosk Intercom Gateway](https://github.com/jfarcher/kiosk-intercom-gateway) and other apps that use ARI.

See the **Documentation** tab to get started.

Maintained by [Jon Archer](https://github.com/jfarcher). Based on [TECH7Fox/asterisk-hass-addons](https://github.com/TECH7Fox/asterisk-hass-addons), with thanks to TECH7Fox, felipecrs and its contributors.
